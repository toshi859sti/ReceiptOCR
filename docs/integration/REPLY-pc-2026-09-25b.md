## 2. Q1：農家がフラグを変えられるか

**変えられない。今後も PC には作らない。**

- PC の科目・残高登録にフラグの列は無い。DB に値は保存されているが、PC は**起動のたびに全年度の全科目を規則から
  計算し直す**（`OcrRoleBackfiller`）ので、規則がただ 1 つの真実になっている
- ユーザーの判断で、**用途ごとの絞り込みはスマホ側に作ってもらう**ことにした。作るときのお願い：
  - スマホの絞り込みは `ocrRole*` の**内側で**減らす形にしてほしい（フラグが false の科目を足さない）。
    フラグの外の科目は PC の決算整理専用・棚卸専用などで、取引の相手にすると帳簿が崩れる
  - 絞り込みの設定は `accountKey` で持つ（契約 §4.4。改名・並べ替えで壊れない）。`name` が変わった科目の扱いは
    学習と同じく §4.6 に合わせてほしい
  - フラグはもともと「AI にかける前の目安」で、ハードな制約ではない（§4.5）。PC は候補外の科目が来ても
    「要確認」で拾う。この点は変わらない

## 3. Q2：新しく作った科目・作り替えた科目ではどう決まるか

**`OcrRoleRules` がフラグを決める唯一の規則**。`accountKey`・`accountType`・`groupName`・`ledgerAffinity`・`isSystem` から
決め、**`name` は見ない**。決まり方の表は [vocabulary-snapshot.md](vocabulary-snapshot.md) §4.5 に足した。

| 場面 | どうなるか |
|---|---|
| 任意科目の枠に新しく作る | 作った時点で規則を当てる（下の表） |
| 預金口座を足す | 借方 false・通帳の相手 true |
| 作り替え（`name` だけ変わる） | 規則が `name` を見ないので**値は変わらない**。引き継ぐのではなく、同じ入力から同じ値が出る |
| 無効化した枠を有効に戻す | 戻した時点で規則を当て直す（枠の種類が同じなので、結果は無効化の前と同じ） |

枠ごとの値（農家が作った科目）：

| 枠 | `ocrRoleExpenseDebit` | `ocrRoleDepositCounter` |
|---|---|---|
| 任意資産・任意負債 | false | **true**（minor（7）で直した） |
| 田畑・果樹・特殊施設・畜産物 | false | true |
| 任意経費 | true | true |
| 繰戻額・繰入額 | **false** | **false**（minor（7）で直した） |
| 預金の口座 | false | true |

**直した 2 つの穴**（どちらも本番 2026 年分には該当する科目が無いので、値もハッシュも変わらない）：

- 任意資産・任意負債（出資金・別枠の借入金など）が通帳の相手科目の候補に入っていなかった。
  帳簿の種類（`ledgerAffinity`）を持たないため、棚卸資産を外す条件に巻き込まれていた
- 繰戻額・繰入額の枠に作った科目が、借方候補・通帳の相手の両方に入っていた。決算整理専用の判定が
  シード科目の名指しだけだった。いまは `groupName` が繰戻額・繰入額なら外す

## 4. Q3：JA 購買とレシートで同じフラグを使うのは意図どおりか

**意図どおり**。PC 側から見ると、どちらも「現金・買掛で経費を払う取引の借方」で、帳簿の上では同じ役割のため 1 本にしている。

- 使う科目の傾向が違う（JA は肥料・農薬・燃料、レシートは消耗品・通信・飲食など）のはそのとおりだが、
  それは「その科目を借方にしてよいか」ではなく「どれが来やすいか」の違いなので、PC のフラグでは分けない
- §2 の絞り込みをスマホ側に作るなら、そこで source ごとに分けてよい。学習（商品名 → 科目）の偏りでも自然に分かれるはず

## 5. Q4：償却資産 3 科目が借方候補にあるのは高額な購入の想定か

**そのとおり**。JA 購買で農機具やハウスの資材を買い、その年の経費ではなく資産に計上する場合を想定している。

- 目安は取得価額 **10 万円以上**（それ未満は農具費・諸材料費などの経費）。スマホの AI への
  「高額な機械・設備を買ったとき以外は資産の科目を使わない」という指示でよい
- 資産に計上した仕訳を取り込んでも、PC の減価償却資産の台帳には自動では載らない。農家が PC で資産を登録する。
  なので、スマホ側で迷ったときは経費に倒してもらって構わない（PC で直せる）

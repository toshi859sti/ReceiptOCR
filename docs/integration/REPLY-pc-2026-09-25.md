## 1. `groupName` ではなく `displayGroup` にした理由

PC の DB の `GroupName` は**決算書内訳の区分**で、決算書（作物の区分、繰戻額を売上から外す処理）・e-Tax の `group` 属性・
`OcrRoleRules` がこの値で判定している。「経費」「資本」を書き込むとこれらが壊れる。

JSON 上の `groupName` だけ画面の名前に差し替える手もあったが、`groupName` の意味が「DB の値」から離れ、
育成費用のように**同じ科目で 2 つの値が要る**場合を表せない。そこで別のキーにした。

## 2. `displayGroup` の中身

[vocabulary-snapshot.md](vocabulary-snapshot.md) §4.1 の「`displayGroup`」に書いた。要点：

- PC の「科目・残高登録」画面のグループ欄に出している名前。**表示専用**（マッチング・候補・参照に使わない）
- 本番 2026 年分の値（64 科目）：

| `displayGroup` | 科目 |
|---|---|
| `償却資産` | `tatemono` `noukigu` `kazyu` |
| `資本` | `motoire` `kouzyo` |
| `田畑` | `suitou` |
| `特殊施設` | `ingen` `kyuuri` |
| `繰戻額` | `kasidaorem` |
| `経費` | `sozei` 〜 `totikairyouhi`（18 科目）、`zappi`、`ikuseihiyou` |
| `(任意) 経費` | `tuusin` `sagyouitaku` `suirihi` |
| `繰入額` | `senzyuusya` `kasidaore` |
| null | 上記以外（現金〜貸付金・口座・土地・土地改良・事業主貸・買掛金〜貸倒引当金・事業主借・家事消費〜雑収入・農外収入・家計費） |

- 農家が任意科目を作ると `(任意) 資産` `(任意) 負債` も出る（空き枠だけのうちは行が無いので出ない）
- 画面では同じ値が続く間の先頭行にだけ名前を出す（スマホ側の作りと同じ）。支出タブの「経費」は
  (任意) 経費を挟んで 2 つの塊になる（租税公課〜土地改良費／雑費・育成費用）。PC の画面もそう見えている
- 値の一覧は固定ではないので、特定の値で分岐しないこと

## 3. 依頼の表と違うところ

- **育成費用（`ikuseihiyou`）は「経費」**。`groupName` は `"繰入額"` だが、PC の画面（らくらくの並び）では雑費に続く
  「経費」の塊に置いている（2026-09-24 に直した）。専従者給与が `繰入額` になり、育成費用が経費へ移るので、
  繰入額は `senzyuusya` → `kasidaore` の 1 つの塊になる。「繰入額 → （なし）→ 繰入額」の割れは解消する
- **営農口座・直売口座は null**。`groupName` は `"普通預金"` だが、PC の画面は口座を普通預金と同じまとまりに描き、
  グループ欄には名前を出していない（普通預金自体がグループ名なし）。`displayGroup` は口座なら親の値にしている

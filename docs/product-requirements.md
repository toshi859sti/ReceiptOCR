# プロダクト要求定義書

## プロダクトビジョン

農業経営者が手書き・印刷の購買伝票を撮影するだけで、
弥生会計・らくらく青色申告（農業版）への仕訳データを自動生成できるようにする。
紙帳票のデジタル化コストをゼロに近づけ、青色申告を完全自力で完結させることが目標。

---

## ターゲットユーザー

**島原雲仙農業協同組合の組合員農家**

### 課題・ニーズ

| 課題 | 詳細 |
|---|---|
| 伝票が紙のみ | JA から発行される購買代金請求明細書は A5 横・3辺緑枠の紙伝票のみ |
| 手入力が負担 | 月数十件の取引を手動で会計ソフトに入力するのに多大な時間がかかる |
| OCR 精度の問題 | 汎用 OCR では農業用品の商品名・数量記載が正確に読み取れない |
| 会計知識の不足 | 農業者は会計ソフトの操作や仕訳知識が乏しい場合が多い |

## 主要機能一覧

### 購買部門

| 機能 | 説明 | 状態 |
|---|---|---|
| 伝票撮影・緑枠検出 | カメラで伝票を撮影し、3辺の緑枠を自動検出して透視変換 | 実装済み |
| OCR（商品名・数量・金額） | Gemini Vision API で伝票全体を読み取り（列クロップTwo-Pass方式） | 実装済み |
| OCR 補正（商品名） | 商品マスタ（product_master）とのcanonicalKey完全一致照合による表記統一 | 実装済み（`ProductNameCorrectorV3`の3層スコアリング補正はPhase6で削除、現行はGemini精度前提の完全一致方式） |
| カテゴリ自動判定 | 小計行の文字列から一般購買／給油所／農業機械を自動分類 | 実装済み |
| 伝票編集 | OCR 結果の手修正（商品名・数量・金額・カテゴリ・日付） | 実装済み |
| 購買 CSV 出力 | らくらく青色申告形式の CSV を生成・共有 | 実装済み |
| 商品マスタ管理 | 正規商品名・カテゴリ・確定フラグの管理 | 実装済み |
| 買掛摘要辞書 | 商品→摘要のマッピング管理 | 実装済み |
| OCR 学習状況 | バリアント学習・昇格状況の確認 | 画面削除済み（`OcrLearningStatusScreen`をPhase6で削除、学習の書き込み経路も非稼働。`ocr_variants`テーブル自体はCSV出力時の商品名照合フォールバックとして残存） |

### 預金部門

| 機能 | 説明 | 状態 |
|---|---|---|
| 通帳データ入力 | 通帳明細の手入力または CSV インポート | 実装済み |
| 摘要マッチング | 通帳摘要テキストからマッチングルールを自動生成 | 実装済み |
| 個別勘定科目オーバーライド | 摘要グループ内の特定行に個別の科目を割り当て | 実装済み |
| 預金 CSV 出力 | らくらく青色申告形式の CSV を生成・共有 | 実装済み |
| 預金摘要辞書 | 摘要テキスト→勘定科目のマッピング管理 | 実装済み |

### 設定・管理

| 機能 | 説明 | 状態 |
|---|---|---|
| 勘定科目設定 | 弥生・らくらく 勘定科目マスタ管理 | 画面実装済み・Navigation 未接続 |
| らくらく摘要辞書 | 共通摘要辞書（購買・預金共用） | 実装済み |
| データエクスポート | DB 全体のバックアップ | 実装済み |
| データインポート | バックアップからの復元 | 実装済み |
| デバッグ撮影 | Step7 有効モードでの精度確認用撮影 | 画面削除済み（`DebugCaptureScreen`をPhase6で削除。`GreenFrameDetector.process()`の`debugMode`パラメータ自体は現存するが呼び出し元なし） |

## 成功の定義

1. 伝票1枚あたりの処理時間が手入力の 1/5 以下になる
2. 商品名・金額の OCR 精度が手修正なしで 80% 以上
3. 青色申告用 CSV を農業者が自力で会計ソフトに取り込める

---

## ユーザーストーリー

```
農業者として、
JA から届いた購買明細書をスマホで撮影するだけで
らくらく青色申告に取り込める CSV ファイルを得たい。
手入力の時間を月次30分以内に削減したい。
```

```
農業者として、
通帳に記載された JA からの入金や引き落としを
摘要テキストから自動で勘定科目に割り当て、
CSV として出力したい。
```

---

## 受け入れ条件

- [ ] 3辺の緑枠を照明・角度変化があっても正しく検出できる
- [ ] 取引明細行のカテゴリ（給油所 / 農業機械 / 一般購買）が正しく割り当てられる
- [ ] 数量・商品名・税込金額が概ね正しく OCR される
- [ ] 弥生 CSV / らくらく CSV の出力フォーマットが会計ソフトで正常に読み込める
- [ ] 撮影から CSV 出力まで1伝票あたり1分以内で完了する

## 1. アプリ概要

JA仕訳変換は、農業経営の証憑を読み取って、会計ソフトに取り込める仕訳データを作るアプリです。

| 証憑 | 読み取り方 |
|------|------|
| JA の購買代金請求明細書 | カメラで撮影すると、緑の枠を見つけてまっすぐに補正し、AI（Gemini）が読み取る |
| 通帳の明細 | 通帳の CSV を取り込む（最大 5 冊） |
| お店のレシート・手書きの領収書 | カメラで撮影すると、AI（Gemini）が読み取る |

作ったデータは、次の会計ソフト向けに書き出せます。

| 会計ソフト | 形式 | 対応している部門 |
|------|------|------|
| 弥生の青色申告 | 仕訳 CSV | 購買・預金・レシート |
| あおいろ帳簿（PC アプリ） | `transactions.json` | 購買・預金・レシート |

> 読み取りにはインターネット接続と Gemini の API キーが必要です。オフラインでは撮影から読み取りはできません。

## 2. はじめに設定すること

メインメニュー →「設定」で、次の 3 つを先に決めておきます。

1. **作業年**：＋／－で令和の年を合わせる（例：令和7年＝2025年）。各画面で最初に表示される年になります
2. **連携会計ソフト**：弥生の青色申告／あおいろ帳簿 から選ぶ
3. **Gemini APIキー**：「AIza...」で始まるキーを入れて「保存」

あおいろ帳簿を使うときは、さらに PC で書き出した `vocabulary.json` を「AoiroChobo 科目・摘要を取り込む」（設定 → データ管理）で取り込みます。
取り込むと、商品や摘要にあおいろの科目・摘要を選べるようになります。

> 無料枠の API キーは、送った画像や結果が Google のモデル改善に使われることがあります。JA の伝票には取引先の情報が入るので、
> 請求先アカウントを設定したキーの利用をおすすめします。

## 4. JA購買伝票

### 4.1 伝票データ

撮影した伝票を月ごとに見て、直して、保存する画面です。

#### 画面の見方

- 上段：年（タップで作業年を切り替え）・月・伝票の切り替え（何枚目か）
- 右上：「閲覧」または「編集」（今のモード）
- 表：取引日・商品名・金額。小計行と合計行も伝票どおりに並ぶ
- 表の下：小計・合計の検算結果。合わないときや、カテゴリが決まらない行があるときは色付きの警告が出る

#### 撮影して読み取る

1. 「編集」を押して編集モードにする
2. 新しい伝票なら「伝票追加」
3. 入力方法を「OCR」にして「撮影」
4. 伝票の緑の枠全体が画面に入るように写す（ピントが合うと読み取りに進む）
5. 「OCR処理中...」のあと、読み取った内容が表に入る
6. 内容を確かめて「決定」で保存する

> 1 か所だけ読み違えたときは、OCR モードで直したいセルを選んでから「撮影」すると、その行の範囲だけを読み直します。

#### 手で直す

- 入力方法を「直接」にしてセルをタップすると、入力ダイアログが開く
  - 取引日：数字だけで入れる（例 `070105`＝令和7年1月5日。「年月固定」をオンにすると日だけ）
  - 商品名：購買品の候補から選べる。数字は自動で全角になり、英字は「全角／半角」で切り替える。「一括全角」で全部全角に
  - 金額：半角数字
- 行を選ぶと右下に「行操作」ボタンが出て、行の挿入・クリアなどができる
- 「再計算」で小計・合計とカテゴリを計算し直す
- タイトルバー右上の A- / A+ で表の文字の大きさを変える（この画面だけの設定で、開き直すと 12 に戻る）

#### 保存するとき

「決定」を押すと、保存の前に次を確かめます。当てはまるときはダイアログが出るので、直すか確認してから保存します。

| ダイアログ | 意味 |
|------|------|
| 入力が不完全な行があります | 日付・商品名・金額のどれかが空 |
| 未分類の行があります／小計行が見つからない行があります | 行のカテゴリ（一般購買・給油所・農業機械）が決まらない |
| 小計・合計が一致していません | 金額の合計が伝票の小計・合計と合わない |
| 確信度の低い行があります | AI が自信のない読み取りをした行がある（「一覧を確認する」で行を確認） |

- 「伝票削除」は最後の伝票だけ消せます（途中を消すと、紙の伝票と番号がずれるため）
- 「クリア」は伝票を残して中身だけ消します
- 「キャンセル」で保存せずに編集をやめます

### 4.2 購買データ確認

年ごとの購買データの一覧です。月を選ぶと、その月の合計と伝票ごとの内訳（月次サマリー）を表示します。

### 4.3 購買品目別リスト

伝票に出てきた商品の一覧です。商品ごとに会計ソフトの科目を決めておくと、出力のときにその科目が使われます。

- 上部：品目数・マッチ済（科目が決まっている）・未マッチ
- 「AIで一括提案」：未マッチの商品の科目を AI に提案させ、「全承認」「確定」で反映する
- 検索・並び替え・絞り込み（カテゴリなど）
- 商品をタップ：商品名（全角 30 文字まで）・カテゴリ・科目を変えて「確定保存」。「削除」もここから
  - 科目の欄は連携会計ソフトによって変わる（弥生：弥生勘定科目／あおいろ：あおいろ科目・摘要）
- 商品の統合：同じ商品が別の名前で 2 つあるとき、1 つにまとめる
- 右上の再集計ボタン：伝票データから商品の使用回数を数え直す
- 右下の ＋：商品を手で追加

### 4.4 出力確認画面（購買）

1. 年や期間（開始日〜終了日）で絞り込む
2. 出す行にチェック（「全選択」「全解除」「未出力のみ表示」が使える）
3. 「CSV出力」（あおいろ帳簿のときは「JSON出力」）を押して保存先を選ぶ

- 上部のバッジで、どの会計ソフト向けの形式かを確認できる
- 出力した行には「出力済」の日付が付く
- 弥生の CSV は、科目が決まっていない行を選んでいると出力できない（科目を決めるか、チェックを外す）
- あおいろの JSON は、科目が決まっていない行も出す。出力後に「確定／摘要なし／科目なし」の件数が表示される

## 5. JA預金

### 5.1 通帳データ

通帳の明細を取り込んで一覧する画面です。

#### 通帳を増やす（2 冊以上あるとき）

右上の ⋮ →「通帳の管理」で、通帳を追加します（最大 5 冊）。通帳ごとに次を決めます。

- 名前（例：営農口座）
- 弥生：普通預金の補助科目（弥生で作った補助科目名。空欄なら補助科目なし）
- あおいろ帳簿の口座（あおいろの科目・摘要を取り込んだあとで選べる）

通帳が 2 冊以上になると、画面上部に通帳の切り替えが出ます。

#### CSV の取り込み

1. 右上の ＋ を押して CSV ファイルを選ぶ（他のアプリから CSV を「共有」しても取り込める）
2. 通帳が 2 冊以上あるときは「どの通帳のCSVですか？」で取込先を選ぶ（CSV に口座番号が無く、自動では判別できないため）
3. 結果（追加した件数・既にあって飛ばした件数）が上部に表示される

CSV の形式（UTF-8・1 行目は見出しとして読み飛ばす）：

| 列 | 内容 |
|----|------|
| 1 | 取引日（`YYYY-MM-DD`） |
| 2 | 取引通番 |
| 3 | 摘要 |
| 4 | 金額（入金は正、出金は負） |
| 5 | メモ（省略可） |

- 同じ通帳の、同じ取引日・取引通番の行は取り込まない（重複として飛ばす）
- 取引通番が空の行には、アプリが番号を振る

#### 削除

- 1 冊分だけ消す：⋮ →「通帳の管理」→ 通帳を選ぶ →「この通帳の明細を削除」
- 全部消す：⋮ →「全削除」（すべての通帳の明細が消えます）
- 通帳そのものは、明細を消してから「通帳を削除」で消せる

### 5.2 通帳摘要別リスト

通帳の摘要（「電気料 デンリヨク」など）をまとめて、まとまりごとに科目を決める画面です。

- 上部：合計・マッチ済・未マッチの件数
- 「AIで一括提案」：未マッチの摘要の科目を AI に提案させる
- まとまりの鉛筆ボタン →「グループ編集」で科目を決めて「保存」
- まとまりの中の 1 件だけ別の科目にしたいとき：その明細の「個別変更」。「グループのデフォルトに戻す」で元に戻る
  - グループの科目を保存し直すと、そのまとまりの個別変更は消える
- 科目の選択肢は連携会計ソフトによって変わる（弥生：勘定科目／あおいろ：相手科目と摘要）
- 摘要と科目の対応は通帳をまたいで共通

### 5.3 出力確認画面（預金）

購買と同じ操作で書き出します（[4.4](#44-出力確認画面購買)）。預金では次の点が違います。

- 通帳が 2 冊以上あると「すべての通帳／通帳ごと」で絞り込める
- 弥生の CSV では、普通預金の補助科目に通帳の補助科目が入る。補助科目が空の通帳が 2 冊以上あると警告が出る（弥生で同じ普通預金に混ざるため）
- あおいろの JSON では、預金口座側に通帳に選んだあおいろの口座が入る。口座が決まっていない通帳の明細は出ない

## 6. レシート・領収書

### 6.1 撮影・OCR

1. 「レシート領収書撮影・OCR」でレシートを写して「撮影」
2. 読み取り結果の確認画面で、店舗名・日付・支払方法の科目・商品と金額を確かめる（行の追加・削除もできる）
3. 「保存して次を撮影」で保存し、続けて次を撮る

### 6.2 レシート領収書一覧

保存したレシートの一覧です。

- 年・月・店舗で絞り込める
- タップで中身を見て直せる。品目ごとに「除外」（経費にしない）もできる
- カード右上は「レシートの支払方法の印字 → 今の支払方法の科目」（例：「PayPay → 事業主借」）。レシートごとに変えた科目は色付きの太字
- 中身の画面の「支払方法の科目」をタップすると、そのレシートだけ支払方法の科目を変えられる（撮影後の確認画面でも同じ）。
  あおいろ帳簿のときはあおいろの科目を選ぶ。外して保存すると支払方法のルールに戻る
- 右下の ＋：写真なしで手入力で追加

### 6.3 商品名・但し書きリスト

レシートに出てきた品目を、表記の違いをならしてまとめたものです。まとまりごとに科目を決めます。

- まとまりの鉛筆ボタン →「勘定科目を設定」。1 件だけ違う科目にするときは、まとまりを開いてその明細をタップ（「個別変更」）
  - あおいろ帳簿のときも同じ。個別変更の画面で科目を外して保存すると、まとまりの設定に戻る
  - まとまりの科目を保存し直すと、そのまとまりの個別変更は消える
- 似ている名前のまとまりや、頭に番号が付いた名前（「09 バックシーラー…」など）の候補を探して、まとめられる
- 「AIで一括提案」：科目を AI に提案させる

### 6.4 出力確認画面（レシート）

購買と同じ操作で書き出します（[4.4](#44-出力確認画面購買)）。弥生の CSV は、支払方法の科目が貸方に入ります。

### 6.5 登録番号・店舗・発行者一覧

レシートに書かれた発行者と、適格請求書の登録番号の一覧です。

- 鉛筆で名前を直す（「既存レシートにも反映する」を選ぶと、保存済みのレシートの店舗名も直る）
- 右上の ⋮ →「レシートから取込」：保存済みのレシートから発行者を集め直す

### 6.6 支払方法の科目設定

レシートの支払方法の文字（「クレジット」「PayPay」など）から、貸方の科目を決めるルールです。「ルール追加」でキーワードと科目を登録します。

- 弥生とあおいろの科目は別々に持つ。あおいろ帳簿のときに足したルールは弥生の科目が「弥生未設定」になり、
  弥生の CSV ではそのルールを飛ばす（弥生モードで科目を選べば使われる）

## 9. データ管理（バックアップ・復元）

設定画面の「💾 データ管理」で行います。

### データの種類

| 種類 | 内容 |
|------|------|
| **全データ** | 下の全部 |
| **マスタデータ** | 購買品リスト・通帳摘要のマッチングルール・弥生の勘定科目（あおいろの科目・摘要は含まない。PC から取り込み直す） |
| **購買伝票** | JA 購買伝票 |
| **通帳データ** | 通帳と通帳の明細 |
| **レシート・領収書** | レシート・領収書 |

### エクスポート（バックアップ）

1. 「エクスポート」で種類を選んで「実行」
2. 保存先を選ぶ（ファイル名は日時付き。例：`all_backup_20260926_123456.json`）

### インポート（復元）

1. 「インポート」で種類を選んで「実行」
2. 復元する JSON ファイルを選ぶ

> インポートは今のデータへの追加です。既にある同じデータは飛ばします。
> 2026-09-29 より前のバックアップに入っている、らくらく青色申告の科目・摘要辞書は読み飛ばします（らくらくは使えなくなりました）。

### AoiroChobo 科目・摘要を取り込む

PC のあおいろ帳簿で書き出した `vocabulary.json` を取り込みます。年度が変わったときや、PC で科目・摘要を変えたときに取り込み直します。

### データクリア

1. 「データクリア」で種類を選んで「実行」
2. 確認ダイアログで「削除」

> **この操作は取り消せません。** 先にエクスポートでバックアップを取ってください。

### 購買品の使用回数を再カウント

伝票データから、購買品リストの「使用回数」を数え直します。伝票を手で大きく直したあとに使います。

| 操作 | 内容 |
|------|------|
| タイトルバー右上の A- / A+ | 一覧の文字の大きさ（すべての一覧で共通） |

## 付録: よくある質問

### Q. 読み取りがうまくいかない

1. 緑の枠全体が画面に入り、影がかからないように写す
2. 暗いときは設定の「フラッシュ」をオンにする
3. 通信ができているか、API キーが入っているかを確かめる（「OCR読み取りエラー」が出たら「再撮影」）
4. 一部だけ違うときは、そのセルを選んで読み直すか、「直接」で手で直す

### Q. バックアップはいつ取るべき？

- 月の伝票入力が終わったとき
- 購買品や摘要の科目をまとめて決めたとき
- 機種変更の前

### Q. 別のスマートフォンに引き継ぐには？

1. 古い端末で「全データ」をエクスポート
2. JSON ファイルを新しい端末に移す（クラウドなど）
3. 新しい端末で「全データ」をインポートし、設定（作業年・会計ソフト・API キー）をやり直す

### Q. 作業年を間違えた

設定の「現在の作業年」を正しい年に直してください。保存済みのデータの年は変わりません。

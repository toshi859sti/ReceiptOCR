## 1. アプリ概要

Remoni は農業経営向けの仕訳補助アプリです。
カメラで領収書を撮影してOCRで自動読み取り（購買部門）し、通帳CSVを取り込んで仕訳データを生成（預金部門）する2つの主要機能を持ちます。

### 主な機能

| 機能 | 説明 |
|------|------|
| 購買OCR読み取り | ArUcoマーカーを使った領収書の自動読み取り |
| 伝票管理 | 月単位の購買伝票の入力・編集・閲覧 |
| 通帳データ取り込み | CSVファイルから通帳データを取り込み |
| 仕訳CSV出力 | 購買・預金データをCSV形式で会計ソフト向けに出力 |
| マスタデータ管理 | 商品名・摘要辞書・OCR学習データの管理 |

## 3. 購買部門

### 3.1 伝票データ（伝票入力画面）

購買部門メニューの「伝票データ」から開きます。
月単位で購買伝票を閲覧・編集できます。

#### 画面構成

- **月選択**: 上部の左右矢印ボタンで閲覧月を切り替えます
- **伝票ナビゲーション**: 複数枚の伝票がある場合、左右矢印で切り替えます
- **データグリッド**: 各行に「日付」「商品名」「金額」「分類」を表示

#### 操作方法

| 操作 | 内容 |
|------|------|
| 月選択（←→） | 表示する月を変更 |
| 伝票切替（←→） | 同月内の伝票を切り替え |
| OCRボタン（カメラアイコン） | OCR撮影画面へ移動 |
| 編集モード切替 | 各行を手動で編集 |
| 長押し | 行のアクションメニューを表示（削除・クリアなど） |
| 伝票追加ボタン（＋） | 新しい伝票を追加 |
| 月次サマリー | 月の集計画面へ移動 |

#### 分類の種類

| 分類 | 内容 |
|------|------|
| 未分類 | OCR読み取り直後の未設定状態 |
| 一般購買 | 一般的な購買取引 |
| 給油所 | ガソリン・軽油等の購入 |
| 農業機械 | 農機具・修理費等 |

---

### 3.2 OCR撮影（領収書の自動読み取り）

カメラで専用テンプレートに貼った領収書を撮影し、日付・商品名・金額を自動読み取りします。

#### 事前準備

OCR撮影には **ArUcoマーカー付き専用テンプレート** が必要です。
テンプレートはA4用紙に印刷し、所定の位置に領収書を固定してください。

- **Bブロック**: マーカーID 0〜3 の枠内（取引日・商品名の読み取り領域）
- **Cブロック**: マーカーID 4〜7 の枠内（金額の読み取り領域）

#### 撮影フロー

```
① 開始画面
    ↓ 「OCR開始」ボタン
② Bブロック撮影（日付・商品名）
    ↓ 撮影 → 自動OCR処理
③ Bブロック処理中...
    ↓ 完了
④ Cブロック撮影（金額）
    ↓ 撮影 → 自動OCR処理
⑤ Cブロック処理中...
    ↓ 完了
⑥ 結果確認画面
    ↓ 「確定」ボタン
⑦ 伝票編集画面（確認・修正）
```

#### 撮影のコツ

- 照明は均一にし、影が入らないようにする
- テンプレートが画面全体に収まるように撮影する
- フラッシュが必要な場合は設定でONにする（設定 → フラッシュ）
- カメラは4K解像度で撮影（固定）

### 3.3 伝票編集画面

OCR結果を確認・修正する画面です。

#### 機能

| 操作 | 内容 |
|------|------|
| 各フィールドをタップ | 内容を直接編集 |
| 編集モードアイコン（鉛筆） | 手書き編集モード切替 |
| 再OCRアイコン | OCR撮影画面へ戻って再撮影 |
| 前の伝票 / 次の伝票 | 同月内の他の伝票へ移動 |
| 整合性チェック | 金額の合計と伝票ヘッダーの整合を確認 |

#### 編集モードの種類

| モード | 用途 |
|--------|------|
| **手書き編集モード** | セルをタップして直接入力 |
| **再OCR上書きモード** | 次回OCR時に上書き対象となる行をマーク |

### 3.4 購買品目別リスト

登録されている商品名の一覧を管理する画面です。

#### 表示・絞り込み

| 機能 | 説明 |
|------|------|
| 検索バー | 商品名で絞り込み |
| 並び替え | 使用回数順 / 五十音順 |
| カテゴリフィルタ | 分類別に絞り込み |
| 摘要未設定フィルタ | 買掛摘要が未設定の商品のみ表示 |

#### 商品の編集

商品名をタップするとダイアログが開き、以下を設定できます：

- **商品名（正規名）**: 正式な商品名
- **買掛摘要**: 仕訳時に使用する摘要区分
- **分類**: 一般購買 / 給油所 / 農業機械
- **使用回数**: 伝票データから自動集計（手動変更も可）

---

### 3.5 出力確認画面（購買）

購買データを会計ソフト向けCSVとして出力する前の確認画面です。

#### 操作手順

1. 出力対象の期間（月）を選択
2. 出力予定のデータ一覧を確認
3. 不要な行はチェックを外して除外
4. 「CSV出力」ボタンでファイルを保存

#### 出力データ形式

| 列 | 内容 |
|----|------|
| 日付 | 領収日（YYYY/MM/DD） |
| 摘要 | 買掛摘要名 |
| メモ | 商品名 |
| 金額 | 購入金額 |

## 4. 預金部門

### 4.1 通帳データ

銀行通帳のCSVデータを取り込んで管理する画面です。

#### CSV取り込み手順

1. 「CSV取込」ボタン（＋アイコン）をタップ
2. ファイル選択画面でCSVファイルを選択
3. 取り込み結果がメッセージで表示される

#### CSV形式

ヘッダー行を含む以下の形式のCSVに対応しています（UTF-8）：

| 列 | 内容 |
|----|------|
| 取引日 | YYYY/MM/DD または YYYY-MM-DD |
| 通番 | 取引通番 |
| 摘要 | 銀行の摘要テキスト |
| 金額 | 入出金金額 |

> **重複チェック**: 取引日＋通番の組み合わせで重複を自動判定し、既存データはスキップされます。

#### 一括削除

画面右上の削除アイコンをタップして、全データを一括削除できます（確認ダイアログあり）。

#### 金額の非表示設定

設定画面の「金額を非表示」をONにすると、通帳データの金額が `***` で表示されます（プライバシー保護）。

---

### 4.2 通帳摘要別リスト（摘要マッチング）

通帳データの摘要テキストと、摘要辞書（簿記ソフト連携 → らくらく：摘要辞書 の「預金」）のマッチングルールを管理する画面です。

#### フィルタ機能

| フィルタ | 説明 |
|----------|------|
| 全て / 入金 / 出金 | 取引種別で絞り込み |
| 通帳データありのみ | 実際の取引が存在するルールのみ表示 |
| 未マッチのみ | 摘要辞書に対応する仕訳が設定されていないルールのみ表示 |

#### マッチングルールの編集

ルール行をタップするとダイアログが開き、以下を設定できます：

- **マッチングパターン**: 通帳の摘要テキストとの照合文字列
- **対応する預金摘要**: ルーラク摘要辞書のエントリを選択

---

### 4.3 出力確認画面（預金）

預金データを会計ソフト向けCSVとして出力する前の確認画面です。

#### 操作手順

1. 出力対象の期間（月）と勘定科目を選択
2. 出力予定のデータ一覧を確認
3. 不要な行はチェックを外して除外
4. 「CSV出力」ボタンでファイルを保存

## 5. 設定

メインメニューの「設定」から開きます。

### 購買部門の設定

| 設定項目 | 内容 | デフォルト |
|----------|------|-----------|
| **入力年** | 伝票に記録する年（令和年号）。＋/－で変更。 | 令和7年 |
| **フラッシュ** | OCR撮影時のカメラフラッシュのON/OFF | OFF |
| **カメラ情報** | デバイス・OS情報の表示（参照のみ） | — |
| **OCR学習状況** | OCR誤認識パターンの学習データ表示画面へ移動 | — |

#### 入力年の設定

令和年号を設定します。西暦換算は `2018 + 令和年` です。

- 令和7年 = 2025年
- 令和8年 = 2026年

### 預金部門の設定

| 設定項目 | 内容 | デフォルト |
|----------|------|-----------|
| **金額を非表示** | 通帳データ画面での金額表示を `***` にする | OFF |

## 6. データ管理（バックアップ・復元）

設定画面の「データ管理」セクションで、データのバックアップ・復元・削除ができます。

### データ種別

| 種別 | 内容 |
|------|------|
| **全データ** | 購買伝票 + 通帳データ + マスタデータをまとめてバックアップ |
| **購買伝票** | 購買伝票データのみ |
| **通帳データ** | 通帳明細データのみ |
| **マスタデータ** | 商品リスト + OCR学習データ + 摘要辞書 + マッチングルール |

### エクスポート（バックアップ）

1. エクスポートする種別をラジオボタンで選択
2. 「実行」ボタンをタップ
3. ファイル保存先を選択
4. ファイル名は自動で日時スタンプ付きになります（例: `all_backup_20260226_123456.json`）

> ファイル形式: JSON

### インポート（復元）

1. インポートする種別をラジオボタンで選択
2. 「実行」ボタンをタップ
3. 復元するJSONファイルを選択

> **注意**: インポートは既存データへの追記です。マスタデータは商品名が重複する場合はスキップされます。

### データクリア

1. 削除する種別をラジオボタンで選択
2. 「実行」ボタン（赤色）をタップ
3. 確認ダイアログで「削除」をタップ

> **警告**: この操作は取り消せません。事前にエクスポートでバックアップを取ることを強く推奨します。

### 購買品の使用回数を再カウント

伝票データを再集計して、商品マスタの「使用回数」を更新します。
伝票データを手動で修正した後などに実行してください。

## 7. OCR学習状況

設定画面の「OCR学習状況」から開きます。
OCRが誤認識した文字列と正しい商品名の対応データ（OCRバリアント）を閲覧できます。

| 表示項目 | 内容 |
|----------|------|
| OCR読み取り結果 | OCRが認識した文字列 |
| 正規商品名 | 対応する正しい商品名 |
| スコア | OCR認識の信頼度 |

このデータは自動的に蓄積され、次回以降のOCR精度向上に使用されます。
マスタデータとしてエクスポート・インポートできます（機種変更時の引き継ぎに利用）。

## 付録: よくある質問

### Q. OCRがうまく読み取れない場合は？

1. **照明を確認**: 影が入らないよう、均一な照明環境で撮影してください
2. **フラッシュをON**: 設定 → フラッシュをONにして再撮影
3. **手動修正**: 伝票編集画面で直接入力してください
4. **学習データ蓄積**: 手動修正を繰り返すと、次回から自動補正精度が上がります

### Q. データのバックアップはいつ取るべき？

- 月次の伝票入力が完了したとき
- マスタデータ（商品リスト・摘要辞書）を更新したとき
- 機種変更の前

### Q. 別のスマートフォンに引き継ぐには？

1. 旧端末で「全データ」をエクスポートしてJSONファイルを保存
2. JSONファイルを新端末に転送（クラウド等経由）
3. 新端末のRemoniで「全データ」をインポート

### Q. 入力年の設定を間違えた場合は？

設定画面で「入力年」を正しい令和年号に設定し直してください。
既に登録済みの伝票データの年号は変わりません。

# CSV出力仕様書

ReceiptOCRアプリの出力確認画面からエクスポートされるCSVファイルの仕様。

---

## 共通仕様

| 項目 | 値 |
|------|-----|
| 文字エンコーディング | UTF-8 (BOMなし) |
| 改行コード | LF (`\n`) |
| 区切り文字 | カンマ (`,`) |
| フィールド囲み | カンマ・ダブルクォート・改行を含む場合のみダブルクォート (`"`) |
| エスケープ | ダブルクォート内のダブルクォートは `""` でエスケープ |

---

## 購買CSV

### ファイル名

```
購買_YYYYMMDD_HHmmss.csv
```

例: `購買_20260205_143052.csv`

### ヘッダー行

```
ID,日付,摘要,メモ,金額
```

### 列定義

| 列名 | 型 | 説明 | 例 |
|------|-----|------|-----|
| ID | 整数 | レコード識別子（ReceiptItemテーブルのID） | `123` |
| 日付 | 文字列 | 取引日 (YYYY/MM/DD形式) | `2026/02/05` |
| 摘要 | 文字列 | 買掛摘要名（らくらく摘要マスタから取得） | `肥料` |
| メモ | 文字列 | 商品名（OCR読み取り値） | `ダイアジノン粒剤3` |
| 金額 | 整数 | 金額（税込、正=購入、負=返品/値引） | `1980` or `-500` |

### サンプルデータ

```csv
ID,日付,摘要,メモ,金額
101,2026/02/01,肥料,ダイアジノン粒剤3,1980
102,2026/02/01,農薬,トレボン乳剤500ml,2480
103,2026/02/03,資材,マルチ黒9230,3280
104,2026/02/03,返品,ダイアジノン粒剤3,-1980
```

### 備考

- 摘要が未設定の場合は空文字列
- 小計・合計行は出力対象外（自動的に除外）
- **金額がマイナスの場合は返品・値引きを示す**

---

## 預金CSV

### ファイル名

```
預金_YYYYMMDD_HHmmss.csv
```

例: `預金_20260205_143052.csv`

### ヘッダー行

```
ID,日付,摘要,メモ,金額
```

### 列定義

| 列名 | 型 | 説明 | 例 |
|------|-----|------|-----|
| ID | 整数 | レコード識別子（DepositMeisaiテーブルのID） | `456` |
| 日付 | 文字列 | 取引日 (YYYY-MM-DD形式) | `2026-02-05` |
| 摘要 | 文字列 | 預金摘要名（らくらく摘要マスタから取得） | `売上入金` |
| メモ | 文字列 | 通帳摘要原文 | `フリコミ アグリサービス` |
| 金額 | 整数 | 金額（正=入金、負=出金） | `50000` or `-12500` |

### サンプルデータ

```csv
ID,日付,摘要,メモ,金額
201,2026-02-01,売上入金,フリコミ アグリサービス,50000
202,2026-02-03,電気代,デンキリョウキン,-12500
203,2026-02-05,燃料代,カード ガソリンスタンド,-8500
```

### 備考

- 摘要が未設定の場合は空文字列
- **金額がプラスの場合は入金、マイナスの場合は出金**
- 日付形式が購買CSVと異なる点に注意（ハイフン区切り）

## 商品マスタ共有CSV

ユーザー間で商品名リストを共有するためのエクスポート/インポート用 CSV。

### ファイル名

```
商品マスタ_YYYYMMDD_HHmmss.csv
```

例: `商品マスタ_20260501_120000.csv`

### ヘッダー行

```
商品名,カテゴリ,買掛摘要
```

### 列定義

| 列名 | 型 | 説明 | 例 |
|------|-----|------|-----|
| 商品名 | 文字列 | `product_master.canonicalName`（全角化済み） | `レギュラーガソリン` |
| カテゴリ | 文字列 | `product_master.category`（一般購買/給油所/農業機械） | `給油所` |
| 買掛摘要 | 文字列 | 対応する `rakuraku_tekiyou.tekiyouName`（未設定は空） | `燃料費` |

### サンプルデータ

```csv
商品名,カテゴリ,買掛摘要
レギュラーガソリン,給油所,燃料費
ダイアジノン粒剤３,一般購買,農薬
マルチ黒９２３０,一般購買,農業資材
クボタトラクター点検,農業機械,機械修繕費
```

## 学習データ共有CSV

ユーザー間で OCR 学習データ（誤認識パターン）を共有するためのエクスポート/インポート用 CSV。

### ファイル名

```
学習データ_YYYYMMDD_HHmmss.csv
```

例: `学習データ_20260501_120000.csv`

### ヘッダー行

```
OCRテキスト,商品名,カテゴリ,信頼度
```

### 列定義

| 列名 | 型 | 説明 | 例 |
|------|-----|------|-----|
| OCRテキスト | 文字列 | `ocr_variants.variantText`（全角化済み） | `レキュラーカソリン` |
| 商品名 | 文字列 | 対応する `product_master.canonicalName` | `レギュラーガソリン` |
| カテゴリ | 文字列 | 対応する `product_master.category` | `給油所` |
| 信頼度 | 文字列 | ユーザー向け表示値。`承認済み` または `学習中` | `承認済み` |

> **注意**: 信頼度列の値は `承認済み`（LOCKED または CONFIRMED に対応）と `学習中`（AUTO に対応）の2種類のみ。インポート時は `承認済み` → `CONFIRMED`、`学習中` → `AUTO` として取り込む。

### サンプルデータ

```csv
OCRテキスト,商品名,カテゴリ,信頼度
レキュラーカソリン,レギュラーガソリン,給油所,承認済み
ダイアシノン粒剤３,ダイアジノン粒剤３,一般購買,承認済み
灯|油,灯油,給油所,学習中
マルチ黒,マルチ黒９２３０,一般購買,学習中
```

## インポート時のマージルール

### 商品マスタ インポート

| 条件 | 処理 |
|---|---|
| `canonicalName` と `category` が**両方**一致する既存レコードあり | **スキップ**（同一商品とみなす） |
| 上記以外 | **追加**（新規 `product_master` として登録） |

- `買掛摘要` 列は、対応する `rakuraku_tekiyou.tekiyouName` を名前検索してリンクする。一致する摘要名が存在しない場合は摘要なし（`kaikakeTekiyouId = null`）として登録する

### 学習データ インポート

| 条件 | 処理 |
|---|---|
| `OCRテキスト`（variantText）と `商品名`（canonicalName）が**両方**一致する既存レコードあり | **スキップ** |
| 対応する `product_master` が存在しない | **スキップ**（先に商品マスタをインポートすること） |
| 上記以外 | **追加** |

- 信頼度は取り込み時にそのまま引き継ぐ（`承認済み` → `CONFIRMED`、`学習中` → `AUTO`）
- `LOCKED` バリアントはエクスポート時も `承認済み` として出力し、インポート時は `CONFIRMED` として登録する（LOCKED は手動操作でのみ昇格）
- インポート後の `hitCount` / `highScoreHits` 等の統計カラムは 0 で初期化する

## Windowsアプリ連携時の注意事項

### 文字エンコーディング

UTF-8で出力されるため、Windowsアプリ側で読み込む際は文字コードを指定する必要がある場合がある。

**C# (.NET) の場合:**
```csharp
using (var reader = new StreamReader(filePath, Encoding.UTF8))
{
    // CSVパース処理
}
```

**Python の場合:**
```python
import csv
with open(file_path, 'r', encoding='utf-8') as f:
    reader = csv.reader(f)
    for row in reader:
        # 処理
```

### 日付形式の変換

| CSV種別 | 形式 | 変換例 (C#) |
|---------|------|-------------|
| 購買 | YYYY/MM/DD | `DateTime.ParseExact(dateStr, "yyyy/MM/dd", null)` |
| 預金 | YYYY-MM-DD | `DateTime.ParseExact(dateStr, "yyyy-MM-dd", null)` |

### 金額の符号処理

両CSVとも金額は符号付き整数。

```csharp
int amount = int.Parse(row[4]);
if (amount >= 0) {
    // 購買: 購入 / 預金: 入金
} else {
    // 購買: 返品・値引 / 預金: 出金
}
```

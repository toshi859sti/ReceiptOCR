# JA仕訳変換

島原雲仙農業協同組合の購買代金請求明細書をスマートフォンで撮影し、
弥生会計・らくらく青色申告（農業版）向けの仕訳 CSV を自動生成する Android アプリ。

## 概要

JA が発行する購買代金請求明細書（A5横・3辺緑枠・右辺なし）を台紙不要で直接撮影し、
OpenCV による緑枠検出・透視変換と ML Kit OCR でデータをデジタル化します。
購買明細と通帳明細の両方に対応し、確定申告用の CSV をワンタップで出力できます。

## 主な機能

### 購買部門
- **緑枠自動検出** — 3辺の緑色フレームを検出して透視変換（台紙・ArUco マーカー不要）
- **OCR** — ML Kit 日本語+Latin モデルで商品名・数量・金額を列ごとに読み取り
- **商品名補正** — ProductNameCorrectorV3 による3層スコアリング（TENTATIVE → CONFIRMED → LOCKED）
- **カテゴリ自動判定** — 一般購買 / 給油所 / 農業機械を自動分類
- **伝票編集** — OCR 結果の手修正（商品名・数量・金額・カテゴリ・日付）
- **購買 CSV 出力** — らくらく青色申告形式で出力・共有

### 預金部門
- **通帳明細管理** — 手入力または CSV インポート
- **摘要マッチング** — 通帳摘要から勘定科目マッピングを自動生成
- **個別勘定科目オーバーライド** — 摘要グループ内の特定行に個別科目を割り当て
- **預金 CSV 出力** — らくらく青色申告形式で出力・共有

### その他
- **OCR 学習状況画面** — バリアント学習・昇格状況の確認
- **デバッグ撮影モード** — 行切り抜き・OCR 詳細結果の確認
- **カラーテーマ** — 5種類のプリセット（グリーン / パープル / ブルー / テラ / モノ）
- **データバックアップ / 復元**

## 技術スタック

## 動作環境

- **minSdk**: 24 (Android 7.0)
- **targetSdk**: 34 (Android 14)

## ビルド

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 対象伝票

島原雲仙農業協同組合「購買代金請求明細書」
- サイズ: A5横（203mm × 148mm）
- 枠: 上・下・左の3辺のみ緑色（右辺なし）
- データ部: 縦罫線のみ・横罫線なし
